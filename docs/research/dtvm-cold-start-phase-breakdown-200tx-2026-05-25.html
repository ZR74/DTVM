DTVM Cold-Start Phase Breakdown

Re-ran the full 200-transaction replay set after adding finer EVM CLI timing phases. This report separates cold-start time into state_load, runtime_setup, input_decode, message_setup, pre_execution_checks, and post_execution_cleanup, alongside the existing runtime-internal phases.

Headline: the biggest newly-measured cold-start cost is state loading, not JIT compilation. On the current 200-tx run, mean state_load is about 9.6 ms in SSA Off and 9.2 ms in SSA On, while mean jit_compilation is only 2.6 ms and 1.9 ms respectively. The larger remaining gap is still outside the current statistics envelope.
